## Nigerian Data Exploration Portfolio

This portfolio contains three data projects focused on Nigerian property listings and Nigeria’s GDP data. Each project includes a Jupyter Notebook documenting the analysis, data preparation, and results.

---

## Project 1: Nigerian Property Data Exploration

Project 1 explored a Nigerian property dataset, including its structure, columns, and patterns in property listings.

Notebook: "Project 1 Data Exploration" (./Nigeria%20Dataset-checkpoint.ipynb)

Tools Used:

- Python
- Pandas
- Jupyter Notebook

---

## Project 2: Nigerian Property Dataset Exploration and Cleaning

Project 2 focused on exploring and cleaning the Nigerian property dataset, checking for missing values, inconsistent entries, and duplicate records.

Notebook: "Project 2 Dataset Exploration and Cleaning" (./Nigeria%20Dataset%20Exploration-checkpoint.ipynb)

Tools Used:

- Python
- Pandas
- Jupyter Notebook
- SQL

---

## Project 3: Nigeria GDP Data Pipeline

Project 3 focused on preparing Nigeria’s GDP data using Python and loading it into Supabase. The dataset contains 66 records covering different years.

Notebook: "Project 3 Nigeria GDP Pipeline" (./nigerian_gdp-checkpoint.ipynb)

## Tools Used:

## Nigeria Data Dashboard

The dashboard was created in Metabase to explore Nigerian property listings and Nigeria’s GDP over time.

Dashboard Includes:

- House Prices by State: compares average property prices across states.
- Listings by Property Type: shows the distribution of property listings by type.
- Nigeria GDP Over Time: visualizes Nigeria’s GDP trend across available years.
